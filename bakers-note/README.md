# ベーカーズ％ノート 🧁

製菓レシピを **ベーカーズ％**（粉＝100%）に変換し、倍率や「粉を◯gにする」で分量を自動スケールするアプリ。
レシピは端末内に保存され、**iPhone / Android のホーム画面に追加**してアプリのように使えます（PWA）。

## できること
- 🗂 レシピの保存・一覧・複製・削除
- ⚖️ ベーカーズ％の自動計算（粉を2種類使う場合は合計を基準に）
- 🔢 倍率スケール（×1.5 / ×2 / ×3、または「粉類を◯gにする」）
- 📋 スケール後の分量をコピー（買い出し・仕込みメモに）
- 📤 全レシピの書き出し／読み込み（バックアップ・機種変更に）
- 🌗 ライト／ダークテーマ、オフライン対応

## 公開する（GitHub Pages）— 一度だけの設定
1. このブランチの内容を **`main`** に反映（マージ）します。
2. GitHub のリポジトリ → **Settings → Pages** を開く。
3. **Build and deployment → Source** を **「GitHub Actions」** に設定。
4. `main` への push で `.github/workflows/deploy.yml` が走り、数分で公開URLが出ます。
   - URL の目安：`https://<ユーザー名>.github.io/<リポジトリ名>/`

## ホーム画面に追加
- **iPhone (Safari)**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**：公開URLを開く → メニュー → 「アプリをインストール／ホーム画面に追加」

## ローカルで確認
```bash
# リポジトリのルートで
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 構成
| ファイル | 役割 |
|---|---|
| `index.html` | 画面（一覧／編集） |
| `styles.css` | デザイン |
| `app.js` | ロジック・保存（localStorage） |
| `manifest.webmanifest` | PWA 設定 |
| `sw.js` | オフライン対応 |
| `icons/` | アプリアイコン |

> データは各端末のブラウザ内に保存されます（サーバー送信なし）。機種変更のときは「書き出し」でバックアップしてください。
