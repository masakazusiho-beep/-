# レシピ帳 📓

料理名・材料欄のテンプレに、**Apple Pencilで自由に書き込める**レシピ帳アプリ。
テンプレの上や余白に、手書きでメモ・丸囲み・矢印などを書き足せます。**料理／デザート／ドリンク**で分類。
データは端末内に保存され、**iPad / iPhone のホーム画面に追加**してオフラインでも使えます（PWA）。

## できること
- 📝 テンプレ入力：料理名、材料欄（＋ボタンで何行でも追加・× で削除）
- ✏️ 手書き：テンプレの上にも、余白にも自由に書き込み（Apple Pencilの筆圧に対応）
- 🖊️ ペン4色（黒・赤・鉛筆・蛍光ペン）＋太さ切り替え、🧹消しゴム（なぞった線だけ消える）、↩︎元に戻す
- ✍️ 既定は**Apple Pencilのみ**で描画（指で持っても誤って線が引かれない）。「指でも描ける」に切替可
- 📏 ページが足りなくなったら「＋ページを伸ばす」で下に広げられる
- 🍳🍰🥤 料理／デザート／ドリンクで分類・絞り込み・検索
- ⧉ 複製／🗑 削除、💾 書き出し・📂 読み込み（バックアップ・機種変更）
- 🌗 ライト／ダークテーマ、オフライン対応

## 操作のコツ（iPad）
- **⌨️ 入力モード**：料理名・材料欄をタップして入力（手書きはできません）
- **✏️ 書き込みモード**：Apple Pencilでページ全体に書き込めます（入力欄はロックされます）
- 上のモード切り替えボタンで行き来します

## 公開（GitHub Pages）
`main` への push で `.github/workflows/deploy.yml` が走り、他のアプリと一緒に公開されます。
- URL の目安：`https://<ユーザー名>.github.io/<リポジトリ名>/recipe-book/`
- 初回のみ **Settings → Pages → Source を「GitHub Actions」** に設定してください。

## ホーム画面に追加
- **iPad / iPhone (Safari)**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」

## ローカルで確認
```bash
cd recipe-book && python3 -m http.server 8000
# http://localhost:8000 を開く
```

> データは各端末のブラウザ内に保存されます（サーバー送信なし）。手書きメモも含めて保存されるので、複数端末で使うときや機種変更のときは「💾 書き出し」→「📂 読み込み」で引き継いでください。
