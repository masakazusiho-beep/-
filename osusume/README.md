# おすすめ道具（お菓子作りのアフィリエイトページ）

実際に使ってよかったお菓子作りの道具・材料を、カード形式で紹介する公開ページです。
GitHub Pages で公開され、ホーム画面に追加してアプリのようにも使えます。

TikTok や Instagram のプロフィール、note のリンクに、このページの URL を貼って
「見つけてもらう → おすすめページ → 購入」の導線をつくる用途を想定しています。

## 商品の足し方・リンクの入れ方

`index.html` の先頭にある `PRODUCTS` 配列に商品を追加するだけです。

```js
var PRODUCTS = [
  {
    name: "コンベクションオーブン",   // 商品名
    cat: "オーブン",                  // カテゴリ（絞り込みタグになる）
    emoji: "🔥",                      // アイコン代わりの絵文字
    blurb: "熱風で均一に焼けて…",       // ひとこと紹介
    rakuten: "",                     // もしもで発行した楽天リンク（空なら「準備中」）
    amazon: ""                       // もしもで発行した Amazon リンク（空なら「準備中」）
  }
];
```

- `rakuten` / `amazon` に、もしもアフィリエイトで発行したリンク URL を貼ると、
  そのボタンが有効になります。両方空のあいだは「リンク準備中」と表示されます。
- リンクには自動で `rel="nofollow sponsored"` が付きます（アフィリエイトの作法）。
- `NOTE_URL` に note のトップ URL を入れると、フッターの「note」がリンクになります。
