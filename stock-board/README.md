# ストックボード 📦

お店の **冷凍・冷蔵・常温** の在庫を場所ごとに数えて、＋−で更新し、**要発注リストをコピー**できる在庫アプリ。
データは端末内に保存され、**iPhone / Android のホーム画面に追加**してオフラインでも使えます（PWA）。

## できること
- 🗂 場所ごとの一覧（下の冷凍ストッカー／下冷蔵庫／常温倉庫／上と冷凍庫、追加可）
- ➕➖ 数量をワンタップで増減、タップで細かい数（0.5 など）も入力
- 🔴🟠 発注点を下回ると「要発注」、0 で「在庫切れ」を自動表示
- 📋 発注リストをコピー／📄 全在庫をコピー（LINE・日報にそのまま貼れる）
- 📥 貼り付けで一括追加・更新（「品名 数量」を1行ずつ。同じ品名は数量更新）
- 💾 バックアップの書き出し／📂 読み込み（機種変更・複数端末への引き継ぎ）
- 🌗 ライト／ダークテーマ、オフライン対応

## 公開（GitHub Pages）
`main` への push で `.github/workflows/deploy.yml` が走り、`bakers-note/` と一緒に公開されます。
- URL の目安：`https://<ユーザー名>.github.io/<リポジトリ名>/stock-board/`
- 初回のみ **Settings → Pages → Source を「GitHub Actions」** に設定してください。

## ホーム画面に追加
- **iPhone (Safari)**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**：公開URLを開く → メニュー → 「アプリをインストール／ホーム画面に追加」

## ローカルで確認
```bash
cd stock-board && python3 -m http.server 8000
# http://localhost:8000 を開く
```

> データは各端末のブラウザ内に保存されます（サーバー送信なし）。複数端末で使うときや機種変更のときは「💾 書き出し」→「📂 読み込み」で引き継いでください。
