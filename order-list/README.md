# 発注チェック 📋

**仕入先別商品一覧**をもとにした発注チェックリストアプリ。商品は仕入先ごとにまとまっていて、発注する物にチェックを付け、チェック中の品目だけをコピーして発注に使えます。
データは端末内に保存され、**iPhone / Android のホーム画面に追加**してオフラインでも使えます（PWA）。

## できること
- 🗂 仕入先ごとの一覧（西原商会・岩田産業・山方屋 など、追加可）。「仕入先別商品一覧」の内容を初期データとして登録済み
- ✅ 発注する品目にタップでチェック（発注チェック欄と同じ考え方）
- ⭐ 「頻度多め」な品目は色付きで目立たせる（発注忘れ防止）
- 📋 チェック中の品目だけを仕入先別にまとめてコピー（LINE・電話メモにそのまま貼れる）
- 🌙 日付が変わったらチェックは自動で全解除（次の日の分を新しくチェックできる）
- ↺ 日付が変わる前でも、発注し終わったら手動で全解除
- 💾 バックアップの書き出し／📂 読み込み（機種変更・複数端末への引き継ぎ）
- 🌗 ライト／ダークテーマ、オフライン対応

## 公開（GitHub Pages）
`main` への push で `.github/workflows/deploy.yml` が走り、他のアプリと一緒に公開されます。
- URL の目安：`https://<ユーザー名>.github.io/<リポジトリ名>/order-list/`
- 初回のみ **Settings → Pages → Source を「GitHub Actions」** に設定してください。

## ホーム画面に追加
- **iPhone (Safari)**：公開URLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**：公開URLを開く → メニュー → 「アプリをインストール／ホーム画面に追加」

## ローカルで確認
```bash
cd order-list && python3 -m http.server 8000
# http://localhost:8000 を開く
```

> データは各端末のブラウザ内に保存されます（サーバー送信なし）。複数端末で使うときや機種変更のときは「💾 書き出し」→「📂 読み込み」で引き継いでください。
