# パウンドケーキが分離してボソボソになる失敗の9割はコレが原因｜製菓の科学で解く『バターと卵の乳化』の話

「レシピ通りに作ったのに、なんでうちのだけボソボソなの…？」

パウンドケーキ作りでこの壁にぶつかった人、きっと多いはずです。バターと砂糖を混ぜてフワッといい感じ。そこに溶いた卵をドバッと入れた瞬間——**急に生地がザラザラ、水分が浮いてボソボソに**。

「あれ、なんか分離した…?」

そのまま焼いても、なんだか目が詰まって重たい。ふんわりしない。パサつく。心当たり、ありませんか?

実はこれ、パウンドケーキ失敗の**9割を占める定番トラブル**なんです。そして原因はたった一つ。「乳化(にゅうか)」が壊れていること。

今日はこの「バターと卵の乳化」を製菓の科学からやさしく解きほぐしていきます。理屈がわかると、失敗が「なぜか成功」から「狙って成功」に変わりますよ。

## そもそも「分離」ってなにが起きてるの?

パウンドケーキの生地って、よく考えると不思議です。**油(バター)** と **水分(卵)** を混ぜてるんですよね。

でも、油と水は本来仲が悪い。ドレッシングを置いておくと二層に分かれるアレと同じです。放っておけば必ず分かれる者同士なんです。

それを無理やり「仲良くさせている」状態が乳化。バターの中に、卵の水分が細か~い粒になって均一に散らばっている状態です。マヨネーズをイメージするとわかりやすいですね。

**この乳化が保たれている生地は、なめらかでツヤがあって、口当たりも軽い。**
逆に乳化が崩れると、水分と油が分かれてボソボソ・ザラザラになる、というわけです。

## 結論:分離の原因は「卵の入れ方」と「温度」だけ

先に結論を言ってしまいます。分離を防ぐカギは、たった2つです。

- **卵を一度にドバッと入れない**(少量ずつ数回に分けて加える)
- **バターと卵の温度を揃える**(どちらも室温に戻す)

この2つを守るだけで、失敗の大半は消えます。

「そんなこと?」と思うかもしれません。でも、**なぜそうしないと分離するのか**——この理屈を知らずに作っている人が本当に多い。そして知らないから、分離したときにパニックになって捨ててしまうんです。

ここから先は、
- **なぜ卵を少しずつ入れると乳化が守られるのか**
- **温度が揃っていないと乳化が壊れる科学的な理由**
- **それでも分離してしまったときの、現場でやっている緊急リカバリー法**

を、じっくり解説していきます。分離しても、実はまだ間に合うんです。

## 🔒 ここから先は有料記事です

### なぜ「少しずつ」で乳化が守られるのか

バターに卵を加えるとき、大事なのは**「油の中に水を少しずつ取り込ませる」順番**です。

乳化には限界量があります。バターが一度に受け止められる水分(卵)の量には上限があるんです。ここに卵をドバッと入れると、**バターのキャパを一気にオーバー**。受け止めきれなかった水分がはじき出されて、あの水っぽいボソボソ状態になります。

だから正解は「少量ずつ」。目安はこうです。

- **卵は全量を5〜6回に分けて加える**
- 1回あたり大さじ1〜1.5杯程度
- **その都度、完全に混ざってツヤが戻ってから次を入れる**

ここで一番のポイント。**次の卵を入れる前に、生地がなめらかにツヤっと戻っているか**を必ず確認してください。まだザラついているうちに次を足すと、そこから一気に崩れます。急がば回れ、です。

### 温度が命。「冷たい卵」が乳化を殺す

もう一つの主犯が**温度差**です。

バターは冷えると固まる油。冷蔵庫から出したての卵(5℃前後)を、せっかくやわらかく練ったバターに入れると何が起きるか——**バターが急に冷やされて、部分的に固まる**んです。

固まったバターは水分を抱き込めません。結果、卵の水分が行き場を失って分離。これが「途中まで順調だったのに急にボソッとなった」の正体です。

数字で意識すると失敗しません。

- **バターの理想温度:20〜23℃**(指でスッと押せて跡が残るくらい)
- **卵の温度:20℃前後**(常温に30分〜1時間出しておく)
- 冬場は特に注意。**卵をぬるま湯(30℃程度)に殻ごとつけて温める**と安定します

「冷たいものは入れない」——これだけ覚えておけば十分です。

### 分離してしまった!現場の緊急リカバリー3手

それでも分離することはあります。うちの厨房でも、新人さんがやりがちです。でも慌てて捨てないで。**8割は復活できます。**

現場で実際にやっている直し方を、効く順に紹介します。

**① 湯せんでほんの少し温める**
分離の多くは「冷えて固まった」もの。ボウルの底を40℃くらいの湯に**数秒だけ**当てながら混ぜると、固まったバターがゆるんで再び乳化します。**当てすぎ厳禁**。バターが溶けきると今度は戻せません。

**② レシピの粉を大さじ1〜2、先に入れる**
これが一番実戦的。分離しかけたら、あとで入れる予定の**薄力粉を少量だけ先に投入**します。粉が余分な水分を吸って、生地をつなぎ直してくれる。応急処置として抜群に効きます。

**③ 残りの卵を止めて、ひとまず粉へ進む**
どうしても戻らないときは、卵を足すのをやめて粉合わせの工程へ。多少目が詰まっても、捨てるよりはるかにマシな仕上がりになります。

### 失敗しないためのチェックリスト

作る前にこれだけ確認してください。

| チェック項目 | 目安・ポイント |
|---|---|
| ☐ バターの温度 | 20〜23℃(指跡が残る硬さ) |
| ☐ 卵の温度 | 20℃前後。冬はぬるま湯で温める |
| ☐ 卵は溶いたか | よく溶きほぐして白身のコシを切る |
| ☐ 加える回数 | 全量を5〜6回に分ける |
| ☐ 各回の確認 | ツヤが戻ってから次を入れる |
| ☐ 分離したら | 湯せん数秒 or 粉を大さじ1先に |
| ☐ 混ぜすぎ注意 | 粉投入後は切るように最小限で |

### 現場からの小ネタ

プロの厨房では、**卵と一緒にアーモンドパウダーを少量混ぜておく**レシピが多いんです。理由は乳化の安定。油分を含んだ粉が緩衝材になって、多少雑に卵を入れても分離しにくくなる。家庭でも大さじ1〜2加えると、コクも出て一石二鳥ですよ。

## おわりに

パウンドケーキの分離は、「なんとなく」で作っていると必ずぶつかる壁です。でも**「油に水を少しずつ、温度を揃えて」**という理屈さえ握っていれば、もう怖くありません。分離しても、湯せんと粉で救えることも覚えておいてください。

次回は「**焼いたパウンドケーキが真ん中だけ生焼け・逆に周りがパサつく**」という、オーブンと型の温度の話を科学で解いていきます。乳化の次は「火の通り方」。ここまでセットで理解すると、あなたのパウンドケーキは一段化けますよ。
