# Star Drifter

依存ライブラリなしの、1ファイル完結型ブラウザゲーム（アーケードシューティング）です。

## 遊び方

`index.html` をブラウザで開くだけ。スタートを押すと始まります。

- **目的**: 降ってくる隕石を撃ち落とし、ぶつからずに生き残る。長く戦うほどスピードが上がる。
- **操作**:
  - 移動: `←` `→` または `A` `D` キー、もしくはマウス／タッチでドラッグ
  - 弾は自動発射
- **ライフ**: 隕石にぶつかると減少（初期3）。0でゲームオーバー。
- ベストスコアはブラウザに自動保存されます。

## 技術

- Vanilla JavaScript + Canvas 2D のみ。ビルド不要・外部依存なし・オフライン動作。
- PC（キーボード／マウス）とモバイル（タッチ）の両方に対応。
