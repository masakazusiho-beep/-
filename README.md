# Star Drifter

依存ライブラリなしの、1ファイル完結型ブラウザゲーム（アーケードシューティング）です。

## 遊び方

`index.html` をブラウザで開くだけ。スタートを押すと始まります。

- **目的**: 降ってくる隕石を撃ち落とし、ぶつからずに生き残る。長く戦うほどスピードが上がる。
- **操作**:
  - 移動: `←` `→` または `A` `D` キー、もしくはマウス／タッチでドラッグ
  - 弾は自動発射
- **ライフ**: 隕石にぶつかると減少（初期3）。0でゲームオーバー。
- ベストスコアはブラウザに自動保存されます。

## スマホアプリ風に使う（PWA）

このゲームは **PWA（Progressive Web App）** に対応しています。ホーム画面に追加すると、
アイコンが並び、フルスクリーンで起動し、オフラインでも遊べます。

> ⚠️ PWAのインストールは **HTTPSで配信されている必要があります**。ファイルを直接開く
> （`file://`）だけでは有効になりません。まず下記の手順でWeb公開してください。

### 公開手順（GitHub Pages・無料）

1. このブランチを `main` にマージする。
2. リポジトリの **Settings → Pages** で、Source を **GitHub Actions** に設定する。
3. `.github/workflows/pages.yml` が自動でデプロイし、`https://<ユーザー名>.github.io/<リポジトリ名>/`
   で公開されます。

### ホーム画面に追加

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー（⋮）→ 「アプリをインストール」／「ホーム画面に追加」

## 技術

- Vanilla JavaScript + Canvas 2D のみ。ビルド不要・外部依存なし・オフライン動作。
- PC（キーボード／マウス）とモバイル（タッチ）の両方に対応。
- PWA対応: `manifest.webmanifest`（アイコン・表示設定）＋ `sw.js`（Service Worker によるオフラインキャッシュ）。
- アイコンは `scripts/make_icons.py`（Python標準ライブラリのみ）で生成。
